## ✨ 课程特色

1. **名师沉稳双语精讲（陈老师单人主讲）**：按课本 `29.1 – 29.11` 脉络循序渐进推导，中文建立直觉理解，所有同系物、官能团、IUPAC 词根词缀及物理性质采分术语严格保留课本原版英文，并对易拼错点（如 `buta-1,3-diene` 留 `a`、`ethane-1,2-diol` 留 `e`、反写酯拆键）做专项点拨。
2. **动态声画同步黑板**：每讲配备 3 张课本规范板书卡片（含 `1°/2°/3°` 醇红碳判别图、正反写酯 `C—O` 单键剪刀拆键图、醇氢键 vs 羧酸双氢键二聚体 `dimer` 微观图、丙酮溶水与液液分层对比图），随语音实时高亮聚焦，支持点击任意板书或任意讲授段一键跳读。
3. **6 讲分节微课 + 完整连听合集 MP3（总长 `33:18`）**：支持 `0.85x – 1.5x` 五档倍速、自动连播与每讲 30 秒预习自检快问快答。
